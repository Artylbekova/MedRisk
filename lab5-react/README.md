# Лабораторная №5 — React + TypeScript + REST API

Реализация в `../client`, учебный сервер в `../mock-server`.

Запуск из корня проекта:

- Терминал 1: `node mock-server/server.js`
- Терминал 2: `cd client && npm install && npm run check && npm run build && npm run dev`
- Браузер: `http://localhost:5173`

Для защиты сделайте **собственные** скриншоты: список, создание, редактирование, ошибка остановленного сервера, неизвестный URL (404), вкладка Network.

Ограничения: учебный сервер не хранит изменения между перезапусками, не использует настоящую БД, нет реальной авторизации и клинической ML-модели.
