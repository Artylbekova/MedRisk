
# REST API системы MedRisk

## Назначение

REST API обеспечивает взаимодействие между клиентским приложением React и сервером NestJS.

Обмен данными осуществляется в формате JSON по протоколу HTTPS.

## Основные эндпоинты

| Метод | Адрес | Назначение |
|---|---|---|
| POST | /api/auth/login | Авторизация пользователя |
| GET | /api/patients | Получение списка пациентов |
| POST | /api/patients | Добавление пациента |
| GET | /api/patients/:id | Получение карточки пациента |
| PUT | /api/patients/:id | Изменение данных пациента |
| POST | /api/observations | Добавление медицинских показателей |
| POST | /api/assessments | Расчёт медицинского риска |
| GET | /api/assessments/:id | Получение результата оценки |

## Пример запроса

POST /api/assessments

```json
{
  "patient_id": 15,
  "model_version": "1.0"
}
```

## Пример ответа

```json
{
  "assessment_id": 101,
  "risk_score": 0.32,
  "risk_level": "medium",
  "model_version": "1.0"
}
```

## Обработка ошибок

- 400 — некорректные данные.
- 401 — пользователь не авторизован.
- 403 — недостаточно прав.
- 404 — запись не найдена.
- 500 — внутренняя ошибка сервера.

## Безопасность

Доступ к API защищён авторизацией и разграничением прав пользователей. Медицинские данные передаются по HTTPS. Результаты оценки риска предназначены для поддержки решений врача и не являются самостоятельным диагнозом.
