
# Безопасность MedRisk

## Защита данных
MedRisk обрабатывает конфиденциальную медицинскую информацию пациентов.

Для защиты данных предусматриваются:
- Авторизация пользователей.
- Разграничение прав доступа (RBAC).
- Шифрование соединений через HTTPS.
- Проверка входных данных.
- Журналирование действий пользователей.
- Резервное копирование базы данных.

## Роли пользователей
- Врач — просмотр пациентов и оценка рисков.
- Администратор — управление пользователями и правами доступа.

## Безопасность прогнозирования
Результаты модели машинного обучения носят рекомендательный характер и не заменяют медицинское заключение врача.
