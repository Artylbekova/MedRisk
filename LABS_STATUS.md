# MedRisk: единый проект по лабораторным №1–5

| ЛР | Содержание | Где смотреть | Статус |
|---|---|---|---|
| 1 | Архитектура и компоненты | `docs/` | подготовлена документация |
| 2 | HTTP, REST, Postman | `lab2-http/`, `mock-server/` | коллекция готова; запуск и скриншоты — на компьютере |
| 3 | DOM и Fetch API | `lab3-dom/` | код готов; браузерные скриншоты — на компьютере |
| 4 | strict TypeScript, DTO, guards | `lab4-types/` | исходники готовы; npm check требует Node и зависимости |
| 5 | React CRUD и маршруты | `client/`, `lab5-react/` | исходники готовы; сборка и интерфейс требуют проверки на компьютере |

**Важное отличие:** ЛР №2–3 здесь основаны на доступных методичках *практических работ* №2–3, а не на отдельном полном руководстве лабораторных №2–3. При получении других требований преподавателя проект надо сверить.

**Учебный проект.** Все записи вымышленные. Формула риска — демонстрационные правила, не клиническая модель. Не вводите реальные персональные или медицинские данные.
