# Лабораторная №3 — HTML/CSS/DOM/Fetch

Запустите сервер `node mock-server/server.js` из корня проекта. Откройте `lab3-dom/index.html` в браузере (можно через VS Code Live Server).

Реализованы: семантическая HTML-форма, таблица DOM через `createElement`, обработчики submit/input/click, `fetch` GET/POST/DELETE, динамический поиск, ошибки и состояние загрузки.

В DevTools → Network проверьте HTTP-запросы и приложите реальные скриншоты.
