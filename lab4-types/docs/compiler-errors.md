# Журнал ошибок TypeScript (учебные примеры)

Примеры ошибок, которые нужно самостоятельно воспроизвести в `models.ts` и затем исправить:

1. `age: '45'` вместо числа → TS2322 (string не присваивается number).
2. `status: 'pending'` вместо `active | inactive` → TS2322.
3. `const p: Patient = { ... }` без `createdAt` → TS2741.

Не выдавайте примеры за реальные логи компилятора. Запустите `npm run check`, сохраните вывод ошибки и повторной успешной проверки.
